# pungoyal/homebrew-tap

Homebrew formulae for [dotsync](https://github.com/pungoyal/dotsync), set-and-forget dotfile sync for macOS and Linux.

```sh
brew install pungoyal/tap/dotsync
```

Upgrade with `brew upgrade dotsync`.

dotsync's [release workflow](https://github.com/pungoyal/dotsync/blob/main/.github/workflows/release.yml) generates and pushes the formulae here on every release. They install the release archives, pinned by the SHA-256 in each release's `checksums.txt`. Please don't edit them by hand; report problems at [pungoyal/dotsync](https://github.com/pungoyal/dotsync/issues).
